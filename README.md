## 📚 Tecnologías a Trabajar y Mini Conceptos

Durante este seminario, abordaremos el ciclo completo de desarrollo de software utilizando las siguientes herramientas:

### 1. Repaso de Python
* **¿Qué es?** Es un lenguaje de programación de alto nivel, interpretado y de propósito general, muy valorado por su legibilidad y su potente ecosistema para ciencia de datos, automatización y desarrollo backend.
* **Conceptos clave:** Tipos de datos, estructuras de control, funciones, programación orientada a objetos (POO) y manejo de entornos virtuales (`venv`, `pip`).

### 2. UI/UX (Diseño y Experiencia de Usuario)
* **¿Qué es?** 
  * **UI (User Interface):** Se enfoca en el aspecto visual, diseño de pantallas, botones, tipografías y colores.
  * **UX (User Experience):** Se centra en la vivencia del usuario, la usabilidad, la accesibilidad y la fluidez al navegar por la aplicación.
* **Conceptos clave:** Jerarquía visual, diseño responsivo, accesibilidad (a11y) y wireframing básico antes de codificar.

### 3. FastAPI
* **¿Qué es?** Un framework web moderno y de alto rendimiento en Python para construir APIs, basado en las anotaciones de tipos estándar de Python (`type hints`).
* **Conceptos clave:** Endpoints, validación automática de datos con Pydantic, documentación interactiva automática (Swagger UI / ReDoc) y programación asincrónica (`async/await`).

### 4. TypeScript
* **¿Qué es?** Un superconjunto tipado de JavaScript que compila a JavaScript plano. Añade tipado estático y características avanzadas para mejorar la mantenibilidad del código a gran escala.
* **Conceptos clave:** Tipos primitivos, interfaces, tipos personalizados, genéricos y la prevención de errores en tiempo de compilación.

### 5. Angular
* **¿Qué es?** Un framework robusto y basado en componentes para construir aplicaciones web de una sola página (SPA), desarrollado y respaldado por Google.
* **Conceptos clave:** Arquitectura basada en componentes, directivas, *data binding*, servicios, inyección de dependencias y desarrollo de formularios reactivos.
